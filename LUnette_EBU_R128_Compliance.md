## 1. Scope

This document records the results of running the official **EBU Loudness Test Set v05** (released 30 March 2016 by the EBU PLOUD Group) through LUnette and comparing each measured value against the specification-mandated targets defined in:

- **EBU Tech 3341** — *Loudness Metering: 'R 128 Publication'* (Programme Loudness / Integrated)

Reference implementation used for cross-validation: **FFmpeg 7.x** (`-af ebur128=peak=true`), which uses the same libebur128 internally.

Tolerances applied per EBU Tech 3341 §5.2:

| Metric | Tolerance |

## 7. Measurement Engine Notes

- **libebur128 v1.2.6** is vendored directly into the application (no system dependency).
- Analysis runs on native Apple Silicon (arm64) and Intel (x86_64) via a universal binary.
- Chunked decoding (65 536-frame blocks) ensures correct analysis of files of arbitrary length without loading the full file into memory.
- Concurrent batch analysis uses a capped task group (max 4 simultaneous analyses); each file gets its own isolated `ebur128_state` instance.
- Channel weighting follows ITU-R BS.1770-4: L/R/C at 0 dB, Ls/Rs at +1.5 dB power, LFE excluded.
